# Carrom Aim (iOS)

مساعد تصويب لكيرم **سوا بلاي** على الآيفون:
- **إضافة بث الشاشة** (Broadcast Extension) تقرأ الشاشة وأنت تلعب.
- تلقى اللوحة من الجيوب، وتكشف الأحجار والسهم الأخضر، وتشغّل محرك الفيزياء.
- **نافذة عائمة (PiP)** فوق اللعبة ترسم مسار المضرب وكل حجر، والجيب اللي بيدخل فيه.

## البناء بدون ماك (GitHub Actions، مجاني)
1. سوّ مستودع جديد على GitHub (Private) وارفع محتويات هذا المجلد كلها، ومعها مجلد `.github`.
2. افتح تبويب **Actions**. البناء يشتغل لحاله، أو اضغط **Run workflow**.
3. بعد ما يخلص (تقريباً 5 دقايق) افتح آخر Run، وحمّل `CarromAim-unsigned-ipa` من **Artifacts**.
4. فك الضغط، وبيطلع لك `CarromAim-unsigned.ipa`.

## التوقيع بشهادتك
وقّع الـ IPA بأي أداة توقيع (ESign / Feather / Sideloadly / Scarlet) باستخدام ملف الشهادة `.p12` وملف `.mobileprovision`.
- **مهم:** لازم الأداة توقّع الإضافة اللي داخل `PlugIns/CarromBroadcast.appex` كمان. أغلب الأدوات تسويها تلقائياً.
- إذا الأداة غيّرت الـ Bundle ID، خلّ الإضافة = **Bundle ID التطبيق + `.broadcast`**. التطبيق يدوّر عليها بهالاسم.
- ما يحتاج App Groups. التطبيق والإضافة يتواصلون عن طريق 127.0.0.1، فأي شهادة تمشي.

## الاستخدام
1. افتح **Carrom Aim** ← اضغط زر البث ← اختر Carrom Aim ← **بدء البث**.
2. اضغط **تشغيل النافذة العائمة**.
3. افتح سوا بلاي واسحب السهم الأخضر. المسارات تطلع في النافذة العائمة، وتقدر تكبّرها وتحركها لأي زاوية.

## ضبط الدقة
القيم في `Shared/Physics.swift` (`PhysicsParams`):
- `friction` و`maxSpeed`: المسافة اللي يمشيها الحجر.
- `eWall`: قوة الارتداد من الحافة.
- `arrowFullLen`: طول السهم الأخضر عند القوة 100%.

الألوان وطريقة الكشف في `Broadcast/Analyzer.swift`.
